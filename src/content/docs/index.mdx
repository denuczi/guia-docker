Esta guía enseña Docker desde cero, paso a paso y sin suponer conocimientos previos.
Cada página define un concepto en español claro, explica por qué existe, muestra un
ejemplo mínimo que puedes ejecutar y te dice qué esperar y qué no romper.

## Qué aprenderás

Al terminar esta ruta sabrás crear, iniciar, detener y eliminar contenedores;
construir imágenes con un `Dockerfile`; persistir datos con volúmenes; conectar
contenedores con redes; orquestar varios servicios con Compose; y limpiar el
sistema sin perder datos por accidente.

## Antes de empezar

Necesitas Docker instalado y el demonio en ejecución. Lo verificas así:

```bash title="terminal"
docker version
```

Si ese comando responde sin errores, puedes empezar. Si no, instala Docker
Desktop según tu sistema ([macOS](./install-macos/),
[Windows](./install-windows/) o [Linux](./install-linux/)) antes de continuar.

## Cómo usar cada lección

Cada página sigue el mismo contrato: qué vas a aprender, qué necesitas antes,
el concepto con su ejemplo, el resultado esperado, un error común y el paso
siguiente seguro. Los comandos destructivos siempre explican su consecuencia
antes de pedirte que los ejecutes.
